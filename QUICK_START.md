# Quick Start Guide

## Installation & Setup

### 1. Clone and Install Dependencies
```bash
npm install
# or
yarn install
# or
pnpm install
```

### 2. Configure Environment Variables
Copy `.env.example` to `.env.local` and fill in your values:
```bash
cp .env.example .env.local
```

Add the following to `.env.local`:
- `DATABASE_URL`: Your database connection string
  - Local SQLite: `file:./dev.db`
  - Neon PostgreSQL: `postgresql://user:password@host/database`
- `GEMINI_API_KEY`: Your Google Generative AI API key

### 3. Initialize the Database
The database schema is already defined in `prisma/schema.prisma`.

Generate Prisma client:
```bash
npx prisma generate
```

Apply migrations (if using Neon):
```bash
npx prisma migrate deploy
```

For local SQLite development, migrations are created automatically.

### 4. Start Development Server
```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Features

- **Persistent Chat History**: All conversations are saved to the database
- **AI-Generated Titles**: Chat titles are automatically generated by Gemini
- **Session Recovery**: Last viewed chat is restored on page refresh
- **Real-time Responses**: UI updates immediately while waiting for AI response
- **Responsive Design**: Mobile-friendly interface with collapsible sidebar

## How to Use

1. **Start a New Chat**: Click "New chat" button
2. **Send a Message**: Type your message and press Enter (or click Send)
3. **View Conversation History**: All chats appear in the left sidebar
4. **Delete a Chat**: Hover over a chat in sidebar and click the trash icon
5. **Switch Chats**: Click any chat in the sidebar to load that conversation

## Troubleshooting

### "GEMINI_API_KEY is not configured"
- Ensure you've set `GEMINI_API_KEY` in `.env.local`
- Get an API key from [Google AI Studio](https://aistudio.google.com/app/apikey)

### "DATABASE_URL is not configured"
- Ensure you've set `DATABASE_URL` in `.env.local`
- For local dev, use: `file:./dev.db`

### Chats not persisting
- Check that `DATABASE_URL` points to a valid database
- Verify Prisma migrations have run: `npx prisma migrate deploy`
- Check browser console for API errors

### App freezing on load
- This should be fixed with the hydration updates
- If still occurring, check for JavaScript errors in browser console
- Clear browser cache and sessionStorage

## Architecture

- **Frontend**: Next.js 16 with React 19
- **Backend**: Next.js API routes
- **Database**: SQLite (local) or Neon PostgreSQL (production)
- **AI**: Google Generative AI (Gemini)
