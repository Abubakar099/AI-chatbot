## API Endpoints

### GET /api/chats
- Returns all conversations with full message history
- Response format: `{ conversations: [...] }`
- Used for sidebar population and data hydration

### GET /api/chats/[id]
- Returns messages for a specific chat
- Response format: `{ messages: [...] }`
- Ordered by creation date ascending

### DELETE /api/chats/[id]
- Deletes chat and all associated messages
- Cascading delete via Prisma relation

### PATCH /api/chats/[id]/title
- Updates chat title dynamically
- Accepts JSON body: `{ title: string }`

### POST /api/chat
- Creates new chat or gets response for existing chat
- Input: `{ message: string, chatId?: string, history: Message[] }`
- Response: `{ reply: string, chatId: string, messageId: string, timestamp: string }`

## Database Schema

### Chat Model
- `id`: UUID primary key
- `title`: AI-generated or fallback title
- `createdAt`: Timestamp
- `updatedAt`: Timestamp
- `messages`: Relation to Message model

### Message Model
- `id`: UUID primary key
- `chatId`: Foreign key to Chat
- `role`: "user" | "assistant"
- `content`: Full message text
- `createdAt`: Timestamp
- Cascade delete on chat deletion

## Data Flow

1. **App Load**: ChatContext fetches `/api/chats` → loads all conversations
2. **Restore Session**: SessionStorage "lastChatId" determines if last chat is selected
3. **Select Chat**: Fetch `/api/chats/[id]` → load messages → display conversation
4. **Send Message**: 
   - Optimistic UI update with user message
   - POST `/api/chat` with message + history
   - Database persists both user and assistant messages
   - Sidebar updates with new chat if first message
5. **Page Refresh**: SessionStorage + database restore full conversation state

## Environment Variables Required

- `DATABASE_URL`: SQLite or Neon connection string
- `GEMINI_API_KEY`: Google Generative AI API key

## Known Limitations

- Streaming responses are buffered (not true streaming to client due to API constraints)
- Titles generated only on first message (no auto-update for subsequent messages)
- SessionStorage only persists within same browser tab
